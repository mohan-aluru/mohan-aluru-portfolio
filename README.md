# Mohan Aluru Portfolio — V2

Updated portfolio with:
- User portrait (`profile.jpg`)
- Reference-inspired circular portrait treatment
- Bento-style stats cards
- Terminal/code visual
- Animated tech ticker
- Dark/light mode
- Responsive navigation
- Project showcase
- Interactive blog cards with modal articles
- LeetCode 250+ section
- Achievements/timeline
- Contact section

## Run
Open `index.html` in a browser.

## Resume
Place your PDF as `resume.pdf` beside `index.html` if you want the Resume buttons to open it. The current downloadable package does not duplicate the uploaded PDF automatically; you can copy your resume into the folder and name it `resume.pdf`.

## Personalize before deployment
1. Replace the placeholder LeetCode URL with your real profile.
2. Add GitHub repository links to the project cards.
3. Add your real blog URLs later if you publish the notes externally.
4. Verify the LinkedIn/GitHub usernames.
